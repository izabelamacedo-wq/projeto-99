# Projeto Java Inicial

Projeto desenvolvido para praticar os conceitos
de Programação Orientada a Objetos em Java.

## Conceitos utilizados

- Classes e objetos
- Herança
- Interfaces
- Encapsulamento
- Organização em pacotes

## Estrutura

- Main: executa o programa.
- Pessoa: classe base.
- Aluno: classe que herda de Pessoa.
- Identificavel: interface de identificação.

## Execução

O programa cria um aluno e exibe seu nome,
idade e matrícula.
